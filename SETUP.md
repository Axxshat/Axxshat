# Setup — Akshat's Pixel Profile

This is a GitHub profile README, **not a webpage**. GitHub renders Markdown, HTML, animated GIFs, and supported images; no JavaScript is needed.

## Publish

1. Open your profile repository: https://github.com/Axxshat/Axxshat
2. Upload/replace `README.md`, the **entire `assets/` folder**, and `.github/workflows/snake.yml` from this ZIP. The directories must keep these exact names.
3. Commit to `main`. Visit https://github.com/Axxshat to check the profile.
4. Open the **Actions** tab of `Axxshat/Axxshat` → **Pixel contribution snake** → **Run workflow** once.
5. If the workflow cannot push, open repository **Settings → Actions → General → Workflow permissions** and select **Read and write permissions**. Rerun.
6. On success the action creates/updates the `output` branch; the animated contribution SVG will load in the README and refresh daily.
